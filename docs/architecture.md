# 架构说明

## 数据流

```text
合同 PDF/TXT
    │
    ├─ 数字文本：PyMuPDF
    └─ 扫描页面：华为云 OCR（可选）
            │
            ▼
结构化合同草稿 ──人工确认──> 付款节点台账
                                  │
银行 CSV/XLSX ──规范化/去重──────┤
                                  ▼
                         确定性匹配规则
                    ┌─────────────┼─────────────┐
                    ▼             ▼             ▼
                 自动确认      人工复核       未关联
                    │             │
                    └──────┬──────┘
                           ▼
                     风险规则引擎
                           ▼
             带合同证据的沟通草稿（人工审核）
```

## 可信边界

- 模型和启发式解析器只产生“待确认”合同草稿。
- 自动核销必须同时满足匹配分数不低于0.80且金额完全一致。
- 已确认匹配保留交易占用关系，重复运行不得把同一流水分配给另一节点。
- 金额差异候选最高只能进入人工复核。
- 风险证据来自已确认付款节点，催款草稿不得虚构罚息或法律结论。
- 外发动作只提供复制和导出，系统不保存邮箱凭据，也不自动发送。

## 外部适配器

| 能力 | 默认实现 | 云端实现 | 降级行为 |
|---|---|---|---|
| 文件存储 | 本地租户目录 | 华为云OBS | OBS不可用时继续使用本地存储 |
| PDF识别 | PyMuPDF | 华为云OCR | 扫描件提示需配置OCR |
| 草稿生成 | 确定性模板 | 模型API | 调用异常时回退模板 |
| 数据库 | SQLite | PostgreSQL | Docker Compose内置PostgreSQL |

## 安全

- API通过 `X-Tenant-ID` 执行行级租户过滤；正式版应替换为认证令牌中的租户声明。
- 文件名经过清洗，存储路径验证不能逃逸租户目录。
- 日志与审计事件不存储完整合同正文、银行账号或云端密钥。
- 演示数据完全合成；真实试用材料需先取得授权并完成脱敏。
