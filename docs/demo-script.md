# 三分钟演示脚本

## 0:00—0:20 问题与结果

打开驾驶舱。说明独立顾问签完合同后仍需手工盯付款节点、核对流水和催款。指出当前待回款、逾期金额与风险数量。

## 0:20—0:55 合同变成应收计划

进入“文档与合同”，上传 `demo/sample_contract.txt`。打开核对抽屉，展示客户、金额、日期、置信度以及合同原文引用。修改或确认付款节点，点击“确认进入台账”。

## 0:55—1:35 核对流水

进入“回款核对”，导入 `demo/sample_bank.csv`，运行核对。强调系统按金额、客户、日期和合同编号评分。展示完全一致流水被自动确认，同时展示47,500元候选不会核销48,000元节点。

## 1:35—2:25 风险与草稿

进入“风险处置”，选择岭南智造逾期项目。展示风险说明及合同第4页的原文证据。选择“明确＋邮件”，生成草稿，展示主题、正文和生成依据。点击“标记为已审核”，说明系统只复制或导出，不自动发送。

## 2:25—3:00 工程与商业闭环

回到驾驶舱，指出业务状态已从原始文档变为可执行台账。简述本地降级、Docker交付、审计记录和码道全流程证据。商业模式为独立顾问69元/月创始用户价，后续以真实访谈验证。

## 现场保障

- 演示前点击“重置演示”。
- 保留一段已录制的视频作为网络或云服务故障时的备用。
- 现场使用合成数据，不展示真实客户姓名、银行账号或云密钥。
